# 가이드 세그먼트 규칙 반영 검증 (21회)

> 작성: 2026-05-20 · 질문: 가이드 Sheet1의 규모/주요업종 선정 규칙이 실제 산출에 반영됐는가?
> 대조: 가이드 `1.25년…분석가이드.xlsx` Sheet1 ↔ `2.…김태웅.xlsx` ↔ 확인완료 원자료 ↔ `config/segments.yaml`

## 가이드가 명시한 규칙 (Sheet1 머리글)

1. **규모(공공)별 기준**: `기업:전체 / 1000명 이상 / 300-999명 / 299명 이하 / 공공기관`
2. **주요업종 선정**: 모수 많은 순 **6~7개**, **10개 이상 응답** (예시: 제조·유통·서비스·정보통신·금융/보험·병원·건설 등)
- 분석기준 컬럼 분포: 60개 도표 = 규모기준 / 5개 = 주요업종 / 1개 = 상위 3개만

## 검증 1 — 규모 구간: **정합 (층위 차이)**

| 층위 | 구간 |
|---|---|
| 가이드 **표시** 기준 | 전체 / **1000이상 / 300-999 / 299이하** / 공공 (3단계) |
| 김태웅 **계산** 시트 | 100미만 / 100-300 / 300-500 / 500-1000 / 1000이상 (**5구간**) |
| `segments.yaml` | 100미만 / 100-300 / 300-500 / 500-1000 / 1000이상 (5구간) |

- 5구간은 3단계로 **깔끔히 roll-up**됨: `299이하={100미만,100-300}`, `300-999={300-500,500-1000}`, `1000이상=그대로`.
- 결론: **계산은 5구간(세밀), 표시는 3단계(가이드)**. segments.yaml은 계산층(5구간)을 갖췄으나 **표시 roll-up(3단계)은 미정의** → `chart_specs.yaml`의 `segment_defs.size_tier.rollup`에 추가함.

## 검증 2 — 주요업종 선정: **부분 반영 (기준 시점 차이)**

| 업종 | 원자료 응답수 | 김태웅 최종 | 개별시트 | 판정 |
|---|---|---|---|---|
| 전자/반도체 | 31 | 19 | ○ | raw·최종 모두 ≥10 |
| 자동차/철강 | 26 | 11 | ○ | 〃 |
| 의료/제약 | 27 | 19 | ○ | 〃 |
| 패션/유통 | 31 | 12 | ○ | 〃 |
| 에너지/화학 | 23 | 12 | ○ | 〃 |
| IT/SW | 15 | 14 | ○ | 〃 |
| **금융/보험** | **9** | **11** | ○ | raw<10인데 **재분류 후 ≥10 → 포함** |
| **교육/연구** | **5** | **11** | ○ | 〃 |
| **건설** | **10** | **0** | ✗ | raw≥10인데 **재분류로 소거 → 제외** |
| 일반서비스 | 14 | 0 | ✗ | raw≥10인데 소거 |

- 규칙 "10개 이상 → 개별 분석"은 **재분류 후 최종 카운트** 기준으로 적용됨(raw 기준 아님).
- 선정 수: 가이드 "6~7개" vs 실제 **8개**.
- 가이드 예시 업종(제조·유통·병원…)은 일반 분류이고 실제 R_Cate 코드(전자/반도체·자동차/철강…)는 더 세분 → 예시와 코드 taxonomy 불일치.
- `segments.yaml`은 13개 R_Cate 코드를 나열할 뿐 **"상위 N개 ≥10 개별 분석" 선정 규칙은 미인코딩**.

## 22회 대비 조치

- `chart_specs.yaml` `segment_defs`에 반영:
  - `size_tier`: 5구간 → 3단계 표시 roll-up 명시
  - `major_industry`: "재분류 후 ≥10 개별 분석" 규칙 + 21회 8개 참조 + **22회는 정제 확정 후 재계산** 주석
- 미해결(합의 필요): 주요업종 **선정 시점**(raw vs 재분류 후) — 22회는 [[POPULATION_FILTER_ANALYSIS_21th]]의 업종 재분류 규칙 확정 후라야 일관 적용 가능.
