## 3. 핵심 발견 — 결정론적 규칙으로 재현 불가

후보 필터를 모두 검증했으나 **어느 것도 206을 만들지 못함**:

| 후보 기준 | 결과 N | 김태웅 인력규모 분포 일치? |
|---|---|---|
| 완료 응답만 | 303~305 | ✗ |
| 5필수항목(매출 포함) 충족 | 237 | ✗ (46/49/38/45/59 ≠ 38/39/35/34/60) |
| 직원수+예산+증감 충족 | 302 | ✗ |
| 설문 완성도 ≥70% | 173 | ✗ |
| 설문 완성도 ≥60% | 240 | ✗ |
| 5개 파트 대표문항 모두 응답 | 299 | ✗ |

**결정적 모순**: 1000이상 인력규모 구간이 237기준 59명인데 김태웅은 **60명**(+1). 부분집합이면 불가능 → 김태웅 모집단은 확인완료(237/305)의 단순 부분집합이 **아님**.

## 4. 22회 대비 — "역산" 대신 "사전 정의"

21회 N=206은 black box(수기 curation)였다. 22회는 동일 모호성을 피하려면 **정제 단계 필터를 사전에 명시적·결정론적으로 정의**해야 한다. 제안하는 계층:

| 계층 | 기준(예시) | 자동/수기 | 현재 도구 |
|---|---|---|---|
| L1 완료 필터 | `tesmi_status`=완료 | 자동 | stage2_validate_raw |
| L2 중복 제거 | 사업자번호 동일 시 최신 응답 1건 | 자동(규칙 합의 필요) | **신규 정의 필요** |
| L3 핵심지표 유효 | 직원수·교육예산 유효(>0), 이상치 보정 | 자동+수기 | outlier_rules.yaml |
| L4 모집단 포함 | 분석 대상 정의(예: 매출 임의/공공 처리 규칙) | 합의 필요 | segments.yaml `excluded_from_kim` |
| L5 업종 재분류 | etc·소수 업종 → 통합 라벨 매핑표 | 수기→표준화 | segments.yaml options + **재분류 매핑표 신규** |

### 합의가 필요한 의사결정 (1차 피드백 전 확정 권장)
1. **중복 응답 처리 규칙**: 사업자번호/회사명 동일 시 — 최신? 최다응답? 수기?
2. **공공조직 매출 처리**: 매출 미기입 공공을 모집단에 포함하는가(21회는 포함, 단 -9 수기 제외)
3. **소수 업종 통폐합 임계**: N<몇 명이면 기업기타로 통합하는가
4. **민간 ~80명 제외의 정체**: 21회 분석가에게 제외 사유 확인 — 21회 재현의 마지막 미해결 변수
